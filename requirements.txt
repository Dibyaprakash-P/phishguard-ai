# scikit-learn is pinned to 1.5.x, not merely "<2.0", because the committed
# model artifact is a pickle produced by 1.5.0 and pickles do not survive
# scikit-learn's internal refactors:
#
#   1.5.0  loads          1.5.2  loads
#   1.6.1  FAILS - sklearn.linear_model._sgd_fast.Log was renamed
#   1.9.1  FAILS - sklearn.compose._column_transformer._RemainderColsList removed
#
# A range of ">=1.5.0,<2.0" resolves to the newest release, so a fresh install
# would fetch 1.9.x and the API would refuse to start with a deserialisation
# error. Widen this pin only together with a retrain.
